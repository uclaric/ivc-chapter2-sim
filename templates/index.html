Sim Help

This help is for operating the Sim. It does not provide answers to graded discussion questions.

  • Microphone: choose Speak my response, allow microphone access, talk, then choose Stop & transcribe.
  • Review first: your spoken words appear in the response box. Edit anything the transcription got wrong before sending.
  • Audio: character audio can be turned off at any time. Written dialogue always remains available.
  • Connection: if a request fails, your typed response remains in the box so you can try again.
  • Refresh: the visible transcript is restored after an accidental refresh when the browser session is still available.
